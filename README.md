# Moviwi 经营测算

浏览器内运行的营销预算、渠道利润与经营回收测算工具。

本仓库根目录就是静态发布目录，入口是 index.html，无需构建或安装依赖。

GitHub Pages：在 Settings → Pages 中选择 Deploy from a branch，选择 main 分支及 /(root)。

参数和方案保存在当前浏览器；跨设备通过导出、导入 JSON 传递。不会自动读取广告平台数据或同步到服务器。

默认以 4,000 台、KOL 共 10 万美元、汇率 6.7、其他预留 2% 测算，TVC 不计入本表。

完整的本地源码包另含财务模型及脚本交互测试；20 项检查已通过。浏览器视觉及线上发布结果需单独验收。
